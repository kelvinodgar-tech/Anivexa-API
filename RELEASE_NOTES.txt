Anivexa API v2.2.1 — Release Notes
===================================

Added
-----
- PORT environment variable — configure the local dev server port via .env
  instead of editing server.js. Defaults to 4000 if unset.

Changed
-------
- REDIS_TTL renamed to DEFAULT_REDIS_TTL for clarity (makes it explicit this
  is only the fallback TTL, not the TTL used for every cache entry). Update
  your .env file accordingly — the old REDIS_TTL variable is no longer read.

Upgrade Notes
-------------
- If you have a .env file with REDIS_TTL=..., rename it to
  DEFAULT_REDIS_TTL=... or it will silently fall back to the 900s default.
- No other breaking changes.
